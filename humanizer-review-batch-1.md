# Humanizer pass, batch 1

Five English guides, in order of how many AI writing habits the scan found. Each item is
one proposed change to published copy, with the text exactly as it is now and the new
wording. Edits go into the `*-draft.md` source that each page is built from. All
approved by the owner and applied on 2026-09-23, except B6: `audit-breakbeat.mjs`
protects the phrase "Breakbeat culture", and B6 removed its only sentence, so it stays
as published.

For each guide, keyword phrases from `keywords/<guide>.json`, headings, FAQ questions,
quotes, names and record titles stay word for word. Where a sentence with a keyword
changes, the note says so and the phrase is kept.

**Dashes:** none of these five guides uses a dash to join sentences. The dashes on the
built pages are date ranges (1988–1992), so there is nothing to change.

**Left alone on purpose:** a "not X but Y" sentence stays when it corrects a belief
readers actually hold. For example, "Jungle did not simply change its name to drum and
bass" stays, and so does "The British contribution was not the invention of acid house".
Only contrasts that argue with nobody are cut.
